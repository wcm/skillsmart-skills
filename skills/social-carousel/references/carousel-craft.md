# Carousel craft

## Hooks that work

- **Number + outcome:** "7 layout rules I wish I knew sooner"
- **Contrarian:** "Stop using 12 columns"
- **Before/after:** "From messy deck to board-ready in 20 minutes"
- **Question:** "Why does your logo look cheap?"

## Rhythm

1 hook → points (each: big number, short title, 1–2 sentence body, an example card) → CTA. Keep a visual constant (number position, card position) so swiping feels smooth.

Bricolage Grotesque + DM Sans (default, friendly) · Space Grotesk + Inter (tech) · Fraunces + Inter (editorial) · Archivo Black + Archivo (bold).

## LinkedIn vs Instagram

- LinkedIn: more text tolerance, professional tone, CTA "Follow for more on X" or "Repost if useful".
- Instagram: punchier, CTA "Save this for later" or "Comment GUIDE and I'll send it".
