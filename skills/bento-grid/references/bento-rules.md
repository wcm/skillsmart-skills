# Bento rules

1. **Hierarchy by size.** Biggest tile = most important feature. Never make all tiles equal.
2. **One accent tile.** A solid brand-colour tile anchors the grid; more than one dilutes it.
3. **Rows add up to 6.** wide(4)+tall(2) · half(3)+half(3) · third(2)×3 · strip(6).
4. **Visual in the top 60%, text in the bottom 40%.** Consistent across tiles.
5. **Calm motion.** Hover lifts 4 px and animates one thing inside the visual. No auto-playing chaos.
6. **Radius and gap ratio.** Gap 16 px, radius 20–28 px. Inner padding ≈ radius.
