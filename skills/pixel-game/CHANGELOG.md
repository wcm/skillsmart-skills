# Changelog

## 1.0.0

- First release: retro pixel-art arcade games that reskin an old classic with a story, made for vertical video. A
  shared engine (pixel screen, bloom, synthesised sound, UI kit, deterministic 120 Hz sims), a starter game (Pixel Hop)
  and three complete examples (Flappy Roadster, Model Kombat, Meta Gear Solid), a scaffold script, and tools for
  headless checks, screenshots, sprite sheets and frame-exact demo videos with sound.
