# Changelog

## 2.0.0 — 2026-10-20

- Rebuilt on a frame-by-frame engine: every frame is rendered on its own, so nothing drops however busy a beat is,
  and the teaser scrubs in the browser.
- Five styles: loud (the 1.0 look), swiss, memphis, xerox and bauhaus.
- Four new beats for 20–30 s cuts: type, split, count and grid.
- One script renders 16:9, 9:16 and 1:1; words fit themselves to each frame.
- MP4 directly (ffmpeg is now required), `--audio` lays a track under the video, contact sheets to check before the
  long render.
