# Brand Board — a SkillsMart skill

A one-page brand board from a name and three adjectives: wordmark, palette, type and voice.

**Install:** get it from [skillsmart.io/skills/brand-board](https://skillsmart.io/skills/brand-board) — click **Get it**, copy the prompt, and paste it into Claude (desktop app → Code tab), Cursor or Codex.

Developers: `skillsmart add brand-board`.
