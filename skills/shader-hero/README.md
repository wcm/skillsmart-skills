# Shader Hero — a SkillsMart skill

A landing page whose hero is a dramatic, interactive WebGL shader (liquid chrome, aurora, ink, particles, glass, dunes, plasma) that reacts to the cursor while the headline stays readable.

**Install:** get it from [skillsmart.io/skills/shader-hero](https://skillsmart.io/skills/shader-hero) — click **Get it**, copy the prompt, paste it into Claude (desktop app → Code tab), Cursor or Codex.

Developers: `skillsmart add shader-hero`.
