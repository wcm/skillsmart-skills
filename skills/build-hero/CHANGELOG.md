# Changelog

## 1.0.0 — 2026-11-01
- First release: a pinned hero that plays a build film on scroll, then dusk and an ordered lights-on, with one-scroll
  auto-play in 3 s and a scaffold of readouts.
- Films in short Kling segments between keyframes, generated with Skillsmart credits (`pictures.mjs`, `film.mjs`).
- Tools for the frames (`frames.mjs`: pick, cut, retime, a phone window), lining up the evening pictures (`align.mjs`),
  a headless check (`check.mjs`) and a video (`video.mjs`).
- Four example pages: Tidelight, Misura, Kebun and Cerise.
