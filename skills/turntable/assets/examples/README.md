# Examples

Four sites on the same engine, each with its own look. Each folder has the page (`index.html`, `style.css`) and the
subjects file that made it (`subjects.json`: the prompts, the turn and the stage). The frames are not included, they
are far too heavy: see each site live, or make new subjects with `subjects.mjs`. `new_project.py … --from <name>`
starts a page from one of them.

The examples' photos were made with GPT Image 2.5 on fal.ai; the skill's own tools make photos with nano-banana-pro on
your Skillsmart credits, from the same prompts. Their turns were made with MiniMax H3 Max Turbo, as the tools make them.
