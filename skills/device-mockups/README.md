# Device Mockup Scenes — a SkillsMart skill

Drop in your screenshots and get polished phone, laptop and browser scenes for launches and posts.

**Install:** get it from [skillsmart.io/skills/device-mockups](https://skillsmart.io/skills/device-mockups) — click **Get it**, copy the prompt, and paste it into Claude (desktop app → Code tab), Cursor or Codex.

Developers: `skillsmart add device-mockups`.
