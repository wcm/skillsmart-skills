# OG Card Set — a SkillsMart skill

A matching set of link-preview images for every page of your site, plus the meta tags to use them.

**Install:** get it from [skillsmart.io/skills/og-card-set](https://skillsmart.io/skills/og-card-set) — click **Get it**, copy the prompt, and paste it into Claude (desktop app → Code tab), Cursor or Codex.

Developers: `skillsmart add og-card-set`.
