# Type systems for posters

## Pairings

| Mood | Display | Detail |
|---|---|---|
| Swiss / neutral (default) | Inter Tight 800–900 | JetBrains Mono |
| Grotesk / raw | Archivo Black | Space Mono |
| Condensed / loud | Anton | IBM Plex Mono |
| Editorial | Fraunces 900 (soft 0) | DM Mono |
| Geometric | Syne 800 | Space Grotesk |

## Hierarchy

1. **Title** — one idea, huge. 180–260 px on A3.
2. **Date** — second biggest; the thing people need to remember.
3. **Footer** — when / where / info, in mono, 16–18 px.

## Writing the words

- Turn the event name into 1–3 punchy words: "Design Systems Meetup #12" → "SYSTEMS / MEET / UP".
- Prefer nouns and verbs; drop articles.
- Uppercase for Swiss and orbit; mixed case is fine for brutal titles.

## Signal colours that print well

`#ff3b1f` (signal red), `#0047ff` (Klein blue), `#00b140` (green), `#ffcc00` (yellow), `#ff5fa2` (pink). Avoid neon RGB colours in print PDFs — they dull in CMYK.
